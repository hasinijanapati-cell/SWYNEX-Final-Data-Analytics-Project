# SWYNEX Final Data Analytics Project

## Project Title
Sales Performance Analysis Dashboard

## Problem Statement
The objective of this project is to analyze sales performance and identify
important business trends using sales data. The analysis helps understand
sales performance, product performance and other key business insights.

## Dataset
The dataset contains sales-related information such as order details,
dates, products, quantities and sales values.

## Data Cleaning
The data was cleaned and prepared before analysis.

The cleaning process included:
- Removing duplicate records
- Handling missing values
- Correcting date formats
- Checking data consistency
- Formatting numerical values

## Analysis
The data was analyzed using Excel to identify important sales trends
and performance indicators.

## Dashboard
An interactive Sales Performance Dashboard was created using:
- KPI Cards
- Charts
- Tables
- Filters/Slicers

## Key Insights
- Identified overall sales performance.
- Identified top-performing products.
- Compared sales across different categories.
- Analyzed sales trends over time.
- Identified areas that can help improve business performance.

## Tools Used
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Charts
- Dashboard

## Outcome
The project demonstrates the complete data analytics process from
data cleaning and analysis to dashboard creation and business insights.
